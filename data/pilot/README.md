# Pilot data

AllPreData.csv is a frozen public mirror of Taiwan presale real-price registration data used only to validate the first version of this repository.

Provenance:

- Upstream repository: CGUIM-BigDataAnalysis/BigDataCGUIM
- Upstream path: EMBA_BigData/AllPreData.csv
- Upstream Git blob SHA: 0dea2ba8409808e1e2f08bac673566713762d55e
- Transaction-date range observed in the file: ROC 111/11/01–111/11/10
- Rows: 1200
- Original domain: Taiwan Ministry of the Interior real-price registration Open Data

The production pipeline downloads current data directly from the MOI endpoints documented in the project README. This snapshot is intentionally small enough to keep the method reproducible in Git.
